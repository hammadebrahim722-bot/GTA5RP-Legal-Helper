Legal Helper

Лёгкий Windows-оверлей для быстрых ответов по правилам сервера и законодательной базе. Приложение не хранит огромную локальную базу: запрос идёт на Worker, который читает актуальные официальные страницы форума.

Скачать для Windows

Правила сервера

Сначала выбираешь проект и сервер. Worker ищет правила именно выбранного сервера.

Законодательная база

Законы ищутся отдельно от правил. Если официальный раздел не найден, помощник не придумывает ответ.

Без огромной базы

На компьютере игрока не лежат сотни документов. Источники остаются онлайн и могут обновляться на форуме.

Для работы требуется интернет. AI-ответ формируется по найденному официальному контексту и сопровождается источниками.
