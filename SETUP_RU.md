# GTA 5 RP Legal Helper 3.4 — инструкция С НУЛЯ

Эта инструкция написана так, будто ты **вообще первый раз работаешь с Cloudflare, GitHub и PowerShell**.

Не пропускай шаги. Если видишь команду в сером блоке — её нужно скопировать целиком и вставить в PowerShell.

---

# 0. Что мы в итоге получим

Схема будет такой:

**Игрок → GTA5RP Legal Helper.exe → твой Cloudflare Worker → официальный форум → найденные правила/законы → Groq AI → ответ игроку.**

На компьютере игрока НЕ будет лежать папка с тысячами законов.

**D1 создавать не надо.**

Telegram тоже не нужен.

---

# 1. Что нужно иметь

Тебе понадобятся:

- Windows 10/11.
- Интернет.
- аккаунт Cloudflare;
- аккаунт Groq;
- аккаунт GitHub;
- Node.js LTS;
- желательно .NET 8 SDK, если хочешь собирать EXE прямо на своём ПК.

Если собираешь EXE только через GitHub Actions, .NET можно локально не ставить.

`C:\GTA5RP-Legal-Helper\backend\worker.js`

# 3. Установить Node.js

Node.js нужен тебе для загрузки инструмента Cloudflare.

1. Открой браузер.
2. Перейди на официальный сайт Node.js.
3. Скачай версию **LTS** для Windows.
4. Запусти `.msi`.
5. Нажимай **Next**.
6. Ничего специально не отключай.
7. В конце нажми **Install**.
8. Если Windows спросит разрешение — нажми **Yes / Да**.
9. В конце нажми **Finish**.

После установки:

1. Нажми клавишу **Win**.
2. Напиши `PowerShell`.
3. Открой **Windows PowerShell**.
4. Вставь:

```powershell
node -v
```

5. Нажми Enter.

Потом:

```powershell
npm -v
```

Если появились номера версий — всё хорошо.

# 4. Создать аккаунт Cloudflare

# 5. Создать API-ключ Groq

Groq будет использоваться как AI-сервер.

1. Открой `https://console.groq.com`.
2. Войди или зарегистрируйся.
3. Найди раздел **API Keys**.
4. Нажми **Create API Key**.
5. Назови его, например:

`gta5rp-legal-helper`

6. Создай ключ.
7. Скопируй ключ.

Он выглядит примерно так:

`gsk_XXXXXXXXXXXXXXXX`

**Никому его не отправляй. Не публикуй его в GitHub.**

Если ты уже случайно опубликовал ключ — удали его в Groq и создай новый.

Wrangler — программа, через которую мы отправим Worker в Cloudflare.

Если браузер спросит, разрешить ли Wrangler доступ к Cloudflare:

2. Нажми **Allow**.

После этого вернись в PowerShell.

# 11. Проверить Worker через браузер

Допустим, Cloudflare выдал:

`https://gta5rp-legal-helper-api.xxxxx.workers.dev`

Открой браузер и введи:

`https://gta5rp-legal-helper-api.xxxxx.workers.dev/api/health`

Должен появиться JSON.

Ищи:

`"status":"ok"`

и:

`"mode":"live-forum"`

и:

`"database":"none"`

и:

`"llmConfigured":true`

Если `llmConfigured` = `false`, значит Groq-ключ не был добавлен правильно.

---

# 12. Проверить каталог серверов

В браузере открой:

`https://ТВОЙ-WORKER.workers.dev/api/catalog`

Должен появиться большой JSON со списками проектов и серверов.

Это нужно для того, чтобы список серверов можно было менять на backend без выпуска новой версии EXE.

# 13. Проверить реальный вопрос ДО сборки EXE

Это необязательно, но очень рекомендуется.

Открой PowerShell.

Выполни команду ниже, заменив адрес на свой Worker:

```powershell
$body = @{ project='GTA5RP'; server='Richman · #3'; mode='rules'; question='Что запрещено делать на сервере Richman?' } | ConvertTo-Json
Invoke-RestMethod -Uri 'https://ТВОЙ-WORKER.workers.dev/api/ask' -Method Post -ContentType 'application/json' -Body $body
```

Подожди ответ.

Если всё работает, появятся:

- `answer`
- `sources`
- `meta`

В `sources` должны быть ссылки на официальный форум.

Для GTA5RP серверные правила действительно публикуются отдельно по серверам, а законодательная база находится отдельным разделом форума. Например, официальный форум показывает отдельный раздел правил Richman и отдельную законодательную базу.

# 21. Почему D1 здесь НЕ нужен

Не создавай D1 просто потому, что где-то видишь слово D1.

В этой версии его специально нет.

Worker делает так:

1. получает проект;
2. получает сервер;
3. находит официальный раздел сервера;
4. находит нужные темы;
5. скачивает их онлайн;
6. ищет наиболее подходящие фрагменты;
7. отправляет контекст AI;
8. возвращает ответ и источники.

Поэтому игроку не нужно скачивать огромную базу законов.

Минус этой схемы: если официальный форум полностью недоступен, помощник не сможет получить свежие документы. Это нормально и безопаснее, чем отвечать по старой копии.

---

# 22. Как обновляются правила

Если администрация форума изменила тему, Worker при следующем запросе снова получает актуальную страницу.

У Worker есть короткое кэширование, чтобы не скачивать одну и ту же страницу десятки раз в секунду.

То есть тебе не нужно каждый раз заново собирать EXE только потому, что на форуме поменяли пункт правила.

# 25. Вставить ссылку обновления в Worker

Открой:

`backend\wrangler.toml`

Найди:

```toml
DOWNLOAD_URL = "https://YOUR-SITE.pages.dev/GTA5RP-Legal-Helper.zip"
```

Замени на ссылку GitHub Release.

Например:


Сохрани файл.

```powershell

```

Теперь EXE сможет узнать, что вышла новая версия.

# 27. Что делать, если EXE не запускается

## Windows пишет, что приложение заблокировано

Нажми:

**ПКМ по EXE → Свойства → если есть «Разблокировать» → поставить галочку → Применить → OK.**

Потом снова запусти.

## Окно открывается, но вопрос не работает

Проверь:

1. Интернет.
2. URL в `AppConfig.cs`.
3. `/api/health` в браузере.
4. `llmConfigured:true`.

## Ошибка 429

Это ограничение запросов. Подожди примерно минуту.

## Ошибка 502

Обычно проблема на стороне форума или AI-сервера. Открой `/api/health` и попробуй вопрос ещё раз через несколько минут.

## Ответ говорит, что раздел не найден

Это означает, что Worker не нашёл подходящую официальную страницу. Это специально лучше, чем выдать игроку информацию с другого сервера.

# 29. Важный момент про безопасность ключа Groq

Ключ Groq хранится только как Cloudflare Secret:

`LLM_API_KEY`

Он НЕ находится в EXE.

Игрок получает только запрос к твоему Worker.

Это важно, потому что если положить ключ прямо в C#-программу, его можно было бы достать из EXE.
