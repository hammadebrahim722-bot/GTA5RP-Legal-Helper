# Backend

Cloudflare Worker без D1.

## API

- `GET /api/health` — проверка сервиса.
- `GET /api/catalog` — список проектов/серверов.
- `GET /api/version` — версия клиента и ссылка на скачивание.
- `POST /api/ask` — вопрос.

## Логика

Worker не хранит локальную копию законодательства. Он получает официальные страницы онлайн, извлекает ссылки на нужные разделы и выбирает наиболее подходящие документы по вопросу. Затем найденный контекст передаётся LLM.

Для GTA5RP сначала определяется официальный раздел выбранного сервера. Для «Законодательной базы» отдельно ищется соответствующий раздел. Это сделано специально, чтобы сервер Richman, например, не получил правила другого сервера.

## D1

D1 здесь намеренно НЕ используется. Подключать D1 на первом этапе не нужно.
