# GTA 5 RP Legal Helper 3.4

Коммерческий по архитектуре Windows-оверлей: **EXE → Cloudflare Worker → официальный форум → поиск нужных страниц → AI → ответ + источники**.

## Главное

- Никакой огромной локальной базы правил на ПК игрока.
- D1 не нужен для работы.
- Worker получает актуальные страницы форума онлайн.
- Для GTA5RP сервер выбирается отдельно, после чего Worker ищет раздел именно этого сервера.
- «Правила сервера» и «Законодательная база» разделены.
- Если официальная законодательная база выбранного сервера не найдена, система не подменяет её обычными правилами.
- C# / .NET 8 / WPF.
- Один self-contained Windows x64 EXE.
- F9 — показать/скрыть оверлей.
- F10 — зарезервирован под голосовой режим; распознавание речи в этой версии ещё не подключено.
- Telegram отсутствует.

## Что нужно настроить один раз

1. Cloudflare Worker.
2. API-ключ LLM (Groq).
3. URL Worker в `LegalHelper/Services/AppConfig.cs`.
4. Сборка EXE через GitHub Actions или локально.
5. После первой публикации — URL ZIP в `backend/wrangler.toml` для уведомления об обновлении.

Подробная инструкция: `SETUP_RU.md`.
